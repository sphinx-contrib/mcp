get-header-params

Returns its region argument and the Mcp-Param-Region HTTP header it arrived in. Demonstrates x-mcp-header (a 2026-07-28 Streamable HTTP client mirrors the argument into the header) and JSON Schema 2020-12 input and output schemas.

{
  "type": "object",
  "$schema": "https://json-schema.org/draft/2020-12/schema",
  "properties": {
    "region": {
      "type": "string",
      "description": "A region name, e.g. eu-west. Mirrored into the Mcp-Param-Region HTTP header.",
      "x-mcp-header": "Region"
    },
    "repeat": {
      "type": "integer",
      "minimum": 1,
      "maximum": 3,
      "default": 1,
      "description": "How many times to repeat the region in the result (1-3)"

          "type": "string"

        {
          "type": "null"

    "repeated": {
      "type": "array",

        "type": "string"

gzip-file-as-resource

Compresses a single file using gzip compression. Depending upon the selected output type, returns either the compressed data as a gzipped resource or a resource link, allowing it to be downloaded in a subsequent request: during the current session for a 2025-era client, or for ten minutes at a minted URI on protocol version 2026-07-28.

Input schema:

{
  "type": "object",
  "$schema": "https://json-schema.org/draft/2020-12/schema",
  "properties": {
    "name": {
      "default": "README.md.gz",
      "type": "string",
      "maxLength": 255,
      "description": "Name of the output file (at most 255 characters)"
    },
    "data": {
      "default": "https://raw.githubusercontent.com/modelcontextprotocol/servers/refs/heads/main/README.md",
      "type": "string",
      "format": "uri",
      "description": "URL or data URI of the file content to compress"
    },
    "outputType": {
      "default": "resourceLink",
      "description": "How the resulting gzipped file should be returned. 'resourceLink' returns a link to a resource that can be read later, 'resource' returns a full resource object.",
      "type": "string",
      "enum": [
        "resourceLink",
        "resource"
      ]
    }
  }
}

Annotations:

{
  "title": null,
  "readOnlyHint": false,

trigger-url-elicitation

Trigger a URL elicitation so the client can direct the user to a browser flow. Supports two mechanisms: the request path (elicitation/create, default) which awaits the user’s response, and the error path (UrlElicitationRequiredError, -32042) which signals the client to handle URL elicitation via the error response. Set errorPath=true to use the error path. On protocol version 2026-07-28 the server instead returns the URL elicitation in-band (input_required).

Input schema:

{
  "type": "object",
  "$schema": "https://json-schema.org/draft/2020-12/schema",
  "properties": {
    "url": {
      "type": "string",
      "format": "uri",
      "description": "The URL the user should open"
    },
    "message": {
      "default": "Please open the link to complete this action.",
      "description": "Message shown to the user before opening the URL",
      "type": "string"
    },
    "elicitationId": {
      "description": "Optional explicit elicitation ID. Defaults to a random UUID. 2025-era clients only: the 2026-07-28 in-band request carries no elicitation ID.",
      "type": "string"
    },
    "errorPath": {
      "default": false,
      "description": "Controls which elicitation mechanism is used. When false (default), sends an elicitation/create request (request path). When true, throws a UrlElicitationRequiredError (MCP error code -32042) so the client handles the URL elicitation via the error path rather than waiting for a response. To clear the error, satisfy the prerequisite and retry this call with the same arguments; the retry ignores errorPath and proceeds, so the client does not loop on the same error. 2025-era clients only: protocol version 2026-07-28 has no -32042 error, so there both settings use the in-band input_required flow.",
      "type": "boolean"
    }
  },
  "required": [
    "url"
  ]
}

Annotations:

{
  "title": null,
  "readOnlyHint": false,
  "destructiveHint": false,
  "idempotentHint": false,
  "openWorldHint": true
}

simulate-research-query

Simulates a deep research operation that gathers, analyzes, and synthesizes information. Runs as a task on the io.modelcontextprotocol/tasks extension (protocol version 2026-07-28): the call returns a task handle, and the client polls tasks/get as the task moves through four stages. If ‘ambiguous’ is true and the client supports elicitation, the task pauses with status input_required until the client answers its clarification request with tasks/update.

Input schema:

{
  "type": "object",
  "$schema": "https://json-schema.org/draft/2020-12/schema",
  "properties": {
    "topic": {
      "type": "string",
      "maxLength": 1000,
      "description": "The research topic to investigate (at most 1,000 characters; the task keeps it until it expires)"
    },
    "ambiguous": {
      "default": false,
      "description": "Simulate an ambiguous query that requires clarification (triggers input_required status)",
      "type": "boolean"
    }
  },
  "required": [
    "topic"
  ]
}

Annotations:

{
  "title": null,
